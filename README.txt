STUDY. iPhone向け学習管理アプリ v1.0

内容:
- 今日の学習時間と目標達成率
- 学習タスクの追加・完了・削除
- ストップウォッチ式の学習記録
- 時間を自由設定できるポモドーロ集中タイマー
- 週間・科目別の学習分析
- JSONバックアップ
- ブラウザ内ローカル保存

iPhoneでの利用:
1. このZIPを展開し、index.html等をHTTPS対応のWebホスティング先に配置します。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」→「ホーム画面に追加」。
4. ホーム画面のSTUDY.アイコンから起動します。

注意:
- このZIPをiPhoneの「ファイル」アプリで直接開くだけでは、PWAとしてのインストールやオフライン機能は動作しません。HTTPSで配信してください。
- データはその端末・ブラウザ内に保存されます。SafariのWebサイトデータ削除等で消える場合があるため、設定画面から定期的にバックアップしてください。
- v1.0ではポモドーロは集中時間のカウントダウンを実装。休憩時間は設定値として保存し、集中後の自動休憩切替は今後の改善項目です。
